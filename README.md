## How to Run

1. Make sure the JDK is installed:
   ```bash
   java -version
   ```
2. Compile a file:
   ```bash
   javac FileName.java
   ```
3. Run it:
   ```bash
   java FileName
   ```

> In Eclipse: right-click the file → **Run As → Java Application**.

## Requirements

- JDK 8 or higher
- Any IDE (Eclipse, IntelliJ IDEA, VS Code) or a terminal
